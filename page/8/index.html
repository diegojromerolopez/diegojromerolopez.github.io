WHAT IS THE MOST USEFUL SKILL FOR SOFTWARE ENGINEERS?

It seems having strong language skills is better than being good at math when talking about developing software. I can imagine that that’s because communication is a foundation of software engineering. This discipline is based in communal work. This is no place for lone wolfes.
