Misconceptions about code comments

 Posted on September 2, 2023  | 

I have been working in this industry since 2008, and it seems an idea is spreading through software companies: code comments are considered harmful. Is that true?

Where did all start?

I think that this idea started with the Clean Code book and the subsequent talks by Robert C. Martin.

Uncle Bob (as people use to call him), has the idea that code should be self-explanatory, and if there is a comment, it is because code is not well structured. So the code needs to be refactored, and then, the comment could be removed as the code would be clear enough to be understandable.
