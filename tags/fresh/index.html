How to create a Dockerfile for your deno fresh project

 Posted on December 28, 2024  | 

Sometimes creating a Dockerfile is an art, you need to be aware of what files include in each layer to leverage the docker cache. How can we do this with deno fresh?

Recommended or usual Dockerfile

Most of the examples I have found in the internet (like this one) tend to copy all the files in the same Docker instruction:

FROM denoland/deno:2.1.4

WORKDIR /app

COPY . .
RUN deno cache main.ts
RUN deno task build

USER deno
EXPOSE 8000

CMD ["run", "-A", "main.ts"]
